Button groups

A button group gathers related buttons into a single unit. Press one of the icon buttons below and watch it widen while its neighbours make room — the group itself never changes size.

  • 2 variants
  • 5 sizes · 32 to 136 px
  • Single or multiple selection
Standard Connected

Standard

Buttons of equal weight, spaced apart, each doing its own thing. Press one and it grows by 15 % while its neighbours give back exactly that much, so the row never shifts.

Label buttons squeeze the same way

Connected

Buttons pushed together into one control, separated by 2 px. The outer corners stay round, the inner ones square off, and the selected button morphs back into a full pill.

Single selection — a <label> around a radio button, no JavaScript

Multiple selection — the same markup with checkboxes
