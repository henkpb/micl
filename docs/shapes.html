Shapes

The Shapes component renders the Material Design 3 Expressive shape library as inline SVGs whose path is supplied by the CSS d property. Swapping a shape's class makes the browser morph smoothly from the old outline to the new one.

  • 35 Material shapes
  • Smooth morphing
  • Fill, outline & shadow
Morphing Gallery Theming

Morphing

Pick a shape to morph the examples: a filled shape, an outlined shape, a shape filled with an image and a shadowed shape. When reduced motion is requested, the shapes change instantly.

Gallery

The 35 shapes of the M3 shape library. Each one fills its 100 × 100 viewBox along its longer side.

Theming

Size, colors, outline, shadow and motion are component tokens, so they can be set on the shape or on any ancestor.
